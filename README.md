# Farm Operations Analytics

Operational analytics project that models a vegetable distribution workflow, including order intake, inventory checks, fulfillment preparation, delivery scheduling, and labor tracking.

## Business Context
This project models a real vegetable distribution workflow for a farm serving wholesale markets and buyers. Orders often arrive in inconsistent formats and must be cleaned and standardized before inventory availability can be checked. Confirmed orders are then prepared, scheduled for delivery, and tracked alongside labor activity. The goal of this project is to improve visibility into order fulfillment, inventory shortages, delivery performance, and labor efficiency.

## Problem Statement
Manual and inconsistent order intake can lead to delays, data quality issues, shortages, and poor visibility into operational bottlenecks. This project simulates that workflow and turns it into structured operational reporting.

## Project Objective
The objective is to design a relational data model and analytics workflow that supports order standardization, inventory validation, fulfillment tracking, delivery coordination, and labor analysis.

## In Scope
- Raw and cleaned order data
- Relational SQL schema
- Inventory and fulfillment tracking
- KPI and reporting queries
- Dashboard or analytics summary outputs
- Business insights and recommendations

## Core Workflow
1. Market order submission
2. Order intake and cleaning
3. Inventory availability check
4. Order confirmation
5. Prep list generation
6. Delivery scheduling
7. Worker hours and labor tracking
8. Operational dashboard reporting
